SAN DIG website

How to open:
1. Extract this ZIP folder.
2. Open index.html in your browser (Chrome/Edge/Firefox).
3. Navigate with the menu and More pages dropdown.

Project uses HTML5 and CSS3 only. No JavaScript and no Bootstrap.
The five videos are locally included MP4 clips made from original generated illustrations.
Illustration/media attribution: AI-generated artwork created for this student project (2026).

Files: 17 HTML pages, one shared CSS file, 12 image files, and 5 videos.
Checklists use native HTML checkbox controls and are not automatically saved.
